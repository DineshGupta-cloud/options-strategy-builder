# Options Strategy Builder - Prototype

This repository contains the Phase 1 frontend prototype for the Options Strategy Builder.

Frontend (Phase 1):
- Vite + React + TypeScript
- Tailwind CSS
- Lightweight Charts installed (can be used later)

Windows setup (frontend):
1. Open PowerShell or Windows Terminal.
2. cd into the repository root and then into frontend: `cd frontend`.
3. Install dependencies: `npm install`.
4. Start the dev server: `npm run dev`.
5. Open http://localhost:5173 in your browser.

Notes:
- This is a prototype and uses local sample data in /data.
- Backend and strategy engine will be added in subsequent phases.
